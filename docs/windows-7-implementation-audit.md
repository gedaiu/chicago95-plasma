# Windows 7 implementation audit

Reviewed on 2026-11-20 against all 22 components in the [installer dispatch](../install.sh). The saved desktop configuration selects every component, Aero for the panel, widgets, Start, decoration and login, Windows 7 for boot and sounds, Thunar for Explorer, and live blur during wobble. The switcher, clock face, Start launcher and menu module, Control Panel, and shutdown tool matched their installed copies byte for byte.

## Changes after the audit

The dated observations below describe the desktop before the fixes. Aero now has a distinct Alt+Tab frame, grouped and usage-ranked Start programs, file search, host-dependent power choices and a fullscreen logoff page. The taskbar has a calendar, hover-to-show-desktop, thumbnail highlighting, application Jump Lists and a compact hidden-icons grid. The Control Panel, Run, System Properties, Explorer navigation and Firefox chrome have Aero-specific paths. Setup synchronizes cursor size, supplies Selawik as a Segoe UI fallback and selects lock-screen styling from the login preference. Notifications can aim the balloon tail at a sender-provided horizontal position.

The nested desktop tests open the calendar and hidden-icons grid, exercise a pinned app’s Jump List, and verify that leaving Show desktop restores the window. Login and power tests use a simulated session. [Desktop tests](../tests/aero/test_aero_session.py) · [Shell interactions](../tests/aero/test_aero_shell_interactions.py)

The post-fix visual run passed all 357 checks with zero skips. A separate installer and behavior run passed 367 checks. Follow-up tests also exercised thumbnail hover and release, repeat installation into an offline Thunar profile, and Firefox rendering the installed button stylesheet.

## Reading the visual results

All 344 checks in the Windows 7 visual runner passed with zero skips. A further 237 installer tests and 88 tests covering the switcher, desktop icons, mouse, screensaver, Firefox, Control Panel and clock also passed.

The panel and several controls have comparisons against original Windows 7 captures or sprites. The Start, power, notification, System Properties and preview portraits instead compare against the project’s own images with fixed fonts, representative icons and Fusion styling. An unchanged portrait can preserve a known mismatch. A real power cycle, authentication and physical display handoff are separate from these preview tests.
