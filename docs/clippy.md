# Clippy

The artwork reconstruction and Blender animation project has moved to the sibling
workspace `~/workspace/clippy-upscale`. Its `README.md` documents setup, working
files, video previews, and validation. No remote has been configured yet.

The original sprite player (`bin/chicago95-clippy`), desktop integration, image-pack
helpers, shared runtime artwork, and app integration tests remain in this repository.

The new workspace contains the full authoring documentation formerly at this path,
all Blender authoring/validation tools, source assets, previews, and an ignored
archive of local experiments. Animation reconstruction remains unfinished:
