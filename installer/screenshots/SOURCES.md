# Installer screenshots

The Desktop, Background and desktop theme previews use original Windows desktop captures. The Windows 95, 98 and XP Luna desktops come from GUIdebook, the Windows 2000 and XP Classic desktops from the project's VM captures, and the Windows 7 gadgets desktop from Toasty Technology. The reference catalogue records the sources and capture details. [Windows screenshot sources](../../tests/references/SOURCES.md)

- **sounds.png** shows the Chicago95 Control Panel's Sounds applet, captured with its `--page sounds --screenshot` option.
- **qmmp.png** shows Qmmp's running skinned interface with the Winamp Base 2.91 skin. The crop includes the player and equalizer.
- **firefox.png** shows Firefox running with a temporary profile containing the project's Firefox preferences and Classic userChrome stylesheet.

The wizard header and sidebar in `installer/art` come from bitmap resources 113 and 124 in `I386/SYSSETUP.DL_` on the Windows 2000 Professional CD (volume `ZRMPOEM_EN`). The final-tasks checklist and completion layout follow the dialog resources in the same DLL.
